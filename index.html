Automatic cloud backup

Cloud backup requires a Firebase project to be created and connected once. After connection, CocoaBuy automatically uploads saved changes whenever the internet is available. Firebase configuration values are project identifiers, not your account password.

Cloud setup instructions

  1. Create a Firebase project and register a Web app.
  2. Enable Authentication → Email/Password.
  3. Create a Cloud Firestore database.
  4. Paste the web app configuration above and save it.
  5. Create an account or sign in. Choose the first sync action.

Firestore security rules are provided in the V5 setup guide. Do not launch with open/public database rules.
